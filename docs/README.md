# GroupGen study docs

## Folder layout

```
docs/
  Inclass_data/          Survey CSV exports from Google Forms (INPUT — add new waves here)
    CRPY/
    CSC110/
    CSC412/
    team_roster_template.csv   Schema for RQ2 team roster
    team_rosters.csv           Optional: fill this to unlock RQ2 analyses

  output/                Everything generated by analysis (safe to delete & regenerate)
    tables/              CSV tables (reliability, RQ1/RQ2 tables, …)
    figures/             PNG charts

  GG_analysis.ipynb      RQ-focused notebook (RQ1 feature/outcomes, RQ2 composition)
  rq_study_analysis.py   Analysis helpers for the new research questions
  groupgen_analysis.py   Shared scoring / reliability / longitudinal utilities
  run_crpy_analysis.py   Legacy CRPY one-shot runner
  DataAnalysis.py        Legacy single-class CSC412 script
  ARCHITECTURE.md        App architecture (grouping API / frontend)
```

## Research questions (notebook structure)

| Section | Question |
|---|---|
| **RQ1a** | Feature trajectories (Get-Features / Check-in) by grouping method |
| **RQ1b** | Collaboration satisfaction: GroupGen vs teacher |
| **RQ2** | Feature similarity + team composition → satisfaction (needs roster) |

RQ2 IV is **within-team feature similarity** (not grouping method). Grouping method is the IV for RQ1.

## Where new files go

| You add… | Put it in… |
|----------|------------|
| New survey export | `Inclass_data/<COURSE>/` |
| Team roster for RQ2 | `Inclass_data/team_rosters.csv` (copy from template) |
| Run notebook / `rq_study_analysis.py` | Tables → `output/tables/`, charts → `output/figures/` |

Do not save generated CSVs or PNGs directly under `docs/` — the scripts route outputs into `output/`.

## Quick run

```powershell
cd docs
py -3 rq_study_analysis.py
```

Or open `GG_analysis.ipynb`, select your local Python kernel, and run Setup → Design readiness → RQ sections.

Outputs appear under `output/tables/` and `output/figures/` (filenames prefixed with `rq_` / `rq1_` / `rq2_`).
